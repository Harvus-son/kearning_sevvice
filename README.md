# Learning Space

Центральная стартовая страница для учебных проектов.

## Направления

- **English** — https://harvus-son.github.io/English/
- **Python** — https://github.com/Harvus-son/Python

## Структура

- `index.html` — главная страница и карточки направлений.
- `styles.css` — адаптивное оформление.
- `app.js` — небольшие интерактивные улучшения.

## Публикация через GitHub Pages

1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/ (root)`.
4. Сохраните настройки. После публикации GitHub покажет адрес сайта в этом же разделе.

Страница сделана на HTML, CSS и JavaScript без сборщика и дополнительных зависимостей.
